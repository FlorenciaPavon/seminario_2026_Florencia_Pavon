# Trabajo Práctico Integrador

Este directorio reúne los materiales del trabajo práctico integrador del
Seminario de Actualización 2026.

## Contenido

- [`comparacion_modelos.ipynb`](./comparacion_modelos.ipynb): notebook de
  comparación de modelos.
- [`entregables/`](./entregables/): documentos finales en PDF.
- [`deploy/`](./deploy/): aplicación web para analizar sentimientos, junto con
  sus instrucciones de instalación y ejecución.

Para configurar y ejecutar la aplicación, seguí las instrucciones del
[README de deploy](./deploy/README.md).
